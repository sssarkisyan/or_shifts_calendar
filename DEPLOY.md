# Развёртывание: Streamlit Community Cloud + Google Таблица

Эта версия хранит все пожелания в вашей Google Таблице (не в файле на
диске), поэтому не зависит от того, что Streamlit Cloud может сбрасывать
файлы приложения при перезапуске. Проверено локально: лимит "5 дней Не могу"
с автоматическим откатом, отправка, вход руководителя, свод, экспорт CSV —
через `streamlit.testing` (см. `test_app_flow.py`). Сама интеграция с Google
Таблицей не могла быть протестирована мной напрямую (нужен ваш аккаунт
Google) — после настройки проверьте её и напишите, если что-то не так.

## Шаг 1 — Google Таблица

1. Создайте новую таблицу на https://sheets.google.com — можно пустую,
   называйте как угодно, например «ОРИТ — пожелания».
2. Скопируйте её ID из адресной строки:
   `https://docs.google.com/spreadsheets/d/ЭТОТ_КУСОК_ID/edit` — это
   значение понадобится на шаге 4.
3. Лист/вкладку внутри создавать не нужно — приложение само создаст лист
   `responses` с нужными заголовками при первой отправке пожеланий.

## Шаг 2 — сервис-аккаунт Google (для доступа приложения к таблице)

1. Откройте https://console.cloud.google.com/ → создайте новый проект
   (или используйте существующий).
2. В разделе **APIs & Services → Library** включите **Google Sheets API**.
3. В разделе **APIs & Services → Credentials** → **Create Credentials** →
   **Service account** → задайте любое имя (например `orit-bot`) → Create.
4. Откройте созданный сервис-аккаунт → вкладка **Keys** → **Add Key** →
   **Create new key** → тип **JSON** → скачается файл `xxxxx.json`.
5. Откройте этот JSON-файл текстовым редактором — он понадобится на шаге 5.
6. Скопируйте адрес сервис-аккаунта (поле `client_email` в JSON, выглядит
   как `orit-bot@ваш-проект.iam.gserviceaccount.com`).
7. Вернитесь в Google Таблицу (шаг 1) → кнопка **Настройки доступа** →
   добавьте этот адрес с правом **Редактор**.

## Шаг 3 — репозиторий на GitHub

1. Создайте новый репозиторий на GitHub (публичный или приватный — оба
   подходят для Streamlit Community Cloud).
2. Загрузите туда содержимое папки `streamlit_app/` **кроме**
   `.streamlit/secrets.toml` (такого файла и не должно быть — секреты
   вводятся отдельно на шаге 5 ниже; `.gitignore` уже настроен, чтобы случайно
   его не закоммитить) и кроме `local_data.csv`/`test_app_flow.py` (это
   только для локальной проверки, в репозиторий их брать не обязательно,
   но и не критично, если попадут).

## Шаг 4 — сформировать secrets.toml (не переносите поля вручную)

Ручной перенос полей из JSON в TOML — самый частый источник ошибки
"Invalid format: please enter valid TOML" (в JSON строки заканчиваются
запятыми, которые в TOML не нужны, а `private_key` — многострочный и легко
ломается при копировании). Вместо этого запустите скрипт, который сам
корректно соберёт TOML прямо из скачанного JSON-ключа (шаг 2.4):

```bash
cd streamlit_app
python3 -m pip install tomli_w tomli
python3 make_secrets_toml.py путь/к/скачанному-ключу.json
```

Скрипт спросит код доступа руководителя и ID таблицы (шаг 1.2), сам
проверит, что получившийся TOML валиден, запишет его в
`.streamlit/secrets.toml` (для локальной проверки) и выведет тот же текст
на экран — просто скопируйте всё, что между линиями `====`, в поле Secrets
на следующем шаге.

## Шаг 5 — деплой на Streamlit Community Cloud

1. Зайдите на https://share.streamlit.io/ и войдите через GitHub.
2. **Create app** → выберите репозиторий из шага 3, ветку, и главный файл
   `app.py`.
3. **Advanced settings → Secrets** — вставьте текст, который вывел скрипт
   на шаге 4, целиком, без изменений.
4. **Deploy**. Через 1-2 минуты откроется ссылка вида
   `https://ваше-приложение.streamlit.app`.
5. Откройте ссылку, отправьте тестовые пожелания за любого сотрудника,
   затем откройте вкладку «Свод по отделению» с кодом `manager_passcode` —
   убедитесь, что запись появилась. Затем откройте саму Google Таблицу —
   должен появиться лист `responses` с этой записью.

## Про "засыпание" приложения

Если ссылкой никто не пользовался 12 часов, Streamlit Cloud "усыпляет"
приложение. Следующий, кто откроет ссылку, увидит экран с кнопкой
«Yes, get this app back up!» — после нажатия приложение поднимается
(обычно меньше минуты) и дальше работает как обычно. Данные при этом не
теряются (они в Google Таблице, а не в самом приложении) — это только
не совсем "мгновенный" первый заход после долгого перерыва. Стоит
предупредить сотрудников об этом заранее, чтобы не подумали, что ссылка
сломана.

## Локальная проверка перед деплоем

Без Google-аккаунта (данные сохранятся в `local_data.csv` рядом, только
для проверки, не для реального использования):
```bash
cd streamlit_app
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```
Код доступа руководителя в локальном режиме — `devlocal` (см. `config.py`,
`MANAGER_PASSCODE_FALLBACK`).

С реальной Google Таблицей локально: запустите `make_secrets_toml.py`
(шаг 4 выше) — он сам создаст `.streamlit/secrets.toml` (файл не
коммитится, см. `.gitignore`) — и запустите так же.

Автоматическая проверка логики (лимит "Не могу", отправка, вход
руководителя) без браузера:
```bash
python3 test_app_flow.py
```
