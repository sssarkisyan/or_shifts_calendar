# Портал заявок на отпуск (врачи) — развёртывание

Отдельное приложение в том же репозитории, что и форма пожеланий:
главный файл `vacation_app.py`. Заявки хранятся в той же Google Таблице,
что и пожелания врачей, но на отдельном листе `vacations` (создаётся сам при
первой заявке; рядом — журнал действий `vacation_log`) — лист `responses` с пожеланиями не затрагивается.

## Деплой (~5 минут, Google-часть уже настроена)

1. Закоммитьте и запушьте новые файлы (`vacation_*.py`, обновлённые
   `requirements.txt` и `.gitignore`) в репозиторий `or_shifts_calendar`.
   Уже работающие приложения пожеланий перезапустятся сами — это нормально,
   их код не менялся.
2. https://share.streamlit.io/ → **Create app** → тот же репозиторий и ветка,
   **Main file path: `vacation_app.py`**.
3. **Advanced settings → Secrets** — вставьте те же Secrets, что у деплоя
   пожеланий врачей (откройте его → Settings → Secrets → скопируйте).
   `department` для этого приложения не нужен (будет проигнорирован).
   Нужен другой код руководителя — поменяйте `manager_passcode`.
4. **Deploy** → проверьте: подайте тестовую заявку, войдите в «Свод по
   отделению», одобрите её, скачайте Excel; в Google Таблице появится лист
   `vacations`. Тестовую строку потом удалите прямо в таблице.

## Настройки — vacation_config.py

- `PLAN_YEAR` — год графика (2027).
- `BASE_DAYS` — положено дней в год, всем одинаково (31).
- `CARRYOVER_DAYS` — остаток неиспользованных дней за прошлые периоды, по
  каждому сотруднику; прибавляется к `BASE_DAYS`.
- `OVERLAP_KINDS` / `MAX_OVERLAP_DAYS` — отпуска двух сотрудников этих типов
  (по умолчанию только «основной») могут пересекаться не больше 7 календарных
  дней. Совместители, договорники, заведующий и профессор не ограничены.
- `MAX_CONCURRENT_MAIN` — и одновременно в отпуске не больше 2 основных врачей.
- `MIN_LONG_PART` — минимальная длина хотя бы одной части (14).
- `SUBMISSION_DEADLINE` — после этой даты сотрудники только смотрят статус.

Список врачей — общий с формой пожеланий (`config.py`).

## Как устроено

- Дни отпуска = календарные дни минус праздничные нерабочие дни РФ
  (ст. 120 ТК; 1–8 января, 23 февраля и т.д. — по библиотеке `holidays`).
- Сотрудник подаёт периоды → статус «На рассмотрении». Удалить может только
  свой неодобренный период. Очерёдность подачи значения не имеет: заявки
  коллег «на рассмотрении» подачу не блокируют, только предупреждают.
- Календарь на год у сотрудника: бледно-розовым — дни, на которые коллеги
  (основные) подали заявки, бледно-зелёным — одобренные, серым — недоступные
  (одобрено 2 основным врачам); при наведении — фамилии. Свои периоды обведены.
- Блокируется при подаче: превышение лимита дней, пересечение со своим
  периодом, короткая часть, после которой часть от 14 дней уже не набрать, и
  (для основных) конфликт с ОДОБРЕННЫМИ отпусками: день, где одобрено уже
  2 основным, или пересечение больше 7 дней с одобренным отпуском коллеги.
- Руководитель видит у каждой заявки колонку «Конфликты», меняет статус и
  комментарий в таблице; «Одобрить без конфликтов» одобряет разом только
  заявки, ни с кем не конфликтующие. Нарушения среди уже одобренных
  отпусков выводятся красным (руководитель правилами не ограничен).
- Входа по паролю нет (сотрудник выбирает себя в списке). Защита — прозрачность:
  перед подачей сотрудник подтверждает «Подаю заявку от своего имени: ФИО»,
  удаление — через подтверждение, а все действия (подача, удаление, смена
  статуса) пишутся в журнал — лист `vacation_log` той же таблицы, с временем
  (МСК) и типом устройства. Сотрудник видит историю по своим заявкам, вы —
  весь журнал во вкладке «Свод по отделению».
- Данные из таблицы кэшируются на 1 минуту (лимит Google на чтение), поэтому
  чужая только что поданная заявка может появиться у других с задержкой до
  минуты. Проверка правил при подаче всегда идёт по свежим данным.
- Excel: лист «Свод» + 12 листов-календарей + список всех заявок.

## Проверка локально

`python3 test_vacation_flow.py` — всегда работает с локальным файлом
(`VACATION_LOCAL_BACKEND=1`), даже если рядом лежит настоящий
`.streamlit/secrets.toml`. Посмотреть приложение без записи в таблицу:
`VACATION_LOCAL_BACKEND=1 streamlit run vacation_app.py`.
